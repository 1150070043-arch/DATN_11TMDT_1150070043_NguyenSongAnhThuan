Kiểm tra dữ liệu hồ sơ

Đăng nhập khách rồi mở Hồ sơ cá nhân. Bấm nút bên dưới để đọc lại GET /api/auth/me trên chính website này.

Phép thử hiển thị tên trường và phân loại; không hiển thị giá trị mật khẩu, hash hay token. Response gốc vẫn có thể xem trong DevTools → Network.

Trường API trả vềPhân loại

API trả HTTP 200 ở cả hai bản. Kết luận dựa trên các trường trong response, không dựa riêng vào status hay phần giao diện đang hiển thị.
