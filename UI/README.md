# Bộ ảnh giao diện BookGuard

Ảnh được chụp từ bản Secure tại kích thước desktop 1440 px để dùng làm tài liệu tham chiếu khi thiết kế lại trên Figma.

## Giao diện công khai

1. `01-trang-chu-danh-muc.png` — Trang chủ và danh mục sách
2. `02-chi-tiet-sach.png` — Chi tiết sách
3. `03-dang-nhap.png` — Đăng nhập
4. `04-dang-ky.png` — Đăng ký
5. `05-quen-mat-khau.png` — Quên mật khẩu
6. `06-dat-lai-mat-khau.png` — Đặt lại mật khẩu khi thiếu token
7. `07-xac-minh-email.png` — Xác minh/gửi lại email
8. `08-trang-404.png` — Trang không tồn tại
